## Features

AIVPlayer 0.6.6 fixes macOS automatic updates that could download successfully but fail during installation.

- macOS native runtime files are normalized during staging so executable tools remain executable and bundled dynamic libraries remain writable by the updater.
- The macOS packaged-resource gate now checks HEIF, FFmpeg and whisper.cpp runtime permissions before an artifact can be released.

## 性能与可靠性

- 修复 macOS ShipIt 在替换应用前清理 `com.apple.quarantine` 时，因 HEIF 动态库为只读权限而返回 `Permission denied (Code 13)` 的问题。
- 下载校验和代码签名正常时，更新不会再因为发布包内 native sidecar 权限错误而回退启动旧版本。

## Bug Fixes

- 修复从 0.6.3 / 0.6.5 自动更新到新版本时，安装阶段失败后仍启动旧版本的问题。
- 修复发布包检查只验证资源存在、没有验证 macOS native runtime 所有者写权限的问题。

## 发布与分发

- 0.6.5 已作为不可变版本保留；0.6.6 使用新的 tag、安装包和更新元数据发布，不覆盖已有 Release 资产。
