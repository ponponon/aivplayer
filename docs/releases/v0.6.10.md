## Features

AIVPlayer 0.6.10 adds safer visual-library review tools and improves the editing timeline and Linux distribution experience.

### Visual library review

- Scan indexed media for exact duplicate files using streamed content hashes, with a persistent hash cache that avoids repeating work for unchanged sources.
- Cancel long-running duplicate scans and review grouped duplicate candidates without modifying source files.
- Find visually similar media candidates by reusing existing SigLIP2 vectors and representative timeline frames, with similarity scores, source details, and direct playback access.
- Export a review-only JSON manifest for duplicate candidates, including recommended keep sources and potential reclaimable space without destructive actions.

### Editing and playback

- Clicking the video track now positions the playhead reliably while preserving clip-selection behavior.
- Improved timeline ruler, track typography, waveform interaction, fullscreen layout, and preview sizing across narrow and fullscreen windows.
- Prevented settings and playback overlays from obscuring the active video controls.

## Performance and Reliability

- Duplicate and similar-media scans are bounded, deterministic, cancellable, and isolated from normal playback.
- Linux release validation now checks distribution resources and Snap startup behavior more explicitly, including ALSA runtime loading and Debian update handling.
- Release checks and test wiring were tightened for the new visual-library workflows and platform packaging paths.

## Bug Fixes

- Fixed timeline clicks being swallowed by nested clip event handling, which could leave the playhead at the wrong position.
- Fixed several playback and editor layout issues that caused controls, timeline labels, or video surfaces to overlap, clip, or render at the wrong size.
- Fixed Linux packaging and update metadata paths so branded icons and Debian background updates remain consistent across release formats.
