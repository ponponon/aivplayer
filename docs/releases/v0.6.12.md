## Bug Fixes

- Fixed AIVPlayer not showing up in Ubuntu GNOME's "Default Applications → Video" list, so it can now be selected as the default video player. GNOME looks up candidates by the `video/x-ogm+ogg` type, which the Linux desktop entry now declares for `.deb`, AppImage and Snap builds as well as the Flatpak desktop entry.
