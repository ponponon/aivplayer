## Features

AIVPlayer 0.6.8 expands AI service configuration and gives Clip Collections a safer, reversible workflow.

- AI service profiles now support an independent translation prompt, while preserving the built-in language, subtitle ID, and JSON output constraints. Prompt changes are included in the translation cache key.
- The managed translation service can automatically choose between the mainland gateway and the Cloudflare Worker, with a user-selectable preferred entry point and network-failure fallback.
- Clip Collections now support import preflight, conflict preview and recovery, operation history, field-level change details, filtered history export, and reversible single-item and batch operations such as delete, rename, merge, duplicate, and tag changes.
- The settings and web interfaces now share an accessible custom select control with keyboard navigation, outside-click dismissal, focus restoration, and support for long lists.

## Performance and Reliability

- Translation requests recover correctly when the local proxy is switched on, switched off, or changes port while AIVPlayer is running.
- Collection history uses validated snapshots and source checks so batch actions do not silently apply to the wrong collection or overwrite unexpected source files.
- AI service settings migration handles encrypted legacy translation keys and keeps managed-service configuration separate from custom providers.
- Workflow status and summary panels no longer leave placeholder space or flash stale states during asynchronous operations.

## Bug Fixes

- Fixed the source-file status and import guidance being hidden in narrow collection workflows.
- Fixed collection history conflict entries being incomplete or difficult to inspect before recovery.
- Fixed task-center terminal records so an individual completed, failed, or cancelled task can be removed from both memory and persistent storage.
