## Features

AIVPlayer 0.6.3 adds an out-of-the-box managed translation service for subtitle translation and AI summaries.

- New installations use the built-in Cloudflare Worker by default and call the fixed `glm-4-flash-250414` model through `aivplayer-translation.ponponon-universe.workers.dev`.
- The BigModel API key stays on the Worker and is never bundled into the desktop client.
- Advanced users can switch to a custom OpenAI-compatible service and configure the endpoint, model, API key, and glossary.
- Existing users with previously configured custom translation settings keep using their custom service automatically.
- Managed requests include an anonymous installation device hash for an additional Worker-side device rate-limit dimension; no account is required.

## 性能与安全

AIVPlayer 0.6.3 新增开箱即用的字幕翻译服务。

- 新安装默认使用 Cloudflare Worker，并调用固定的 `glm-4-flash-250414` 模型。
- BigModel API Key 只保存在 Worker 的 Secret 中，不会打入客户端安装包。
- Worker 继续使用设备 / IP 短时限流、每日配额、请求体积和输出 Token 上限保护公共接口。
- 不需要注册账号；客户端只发送不可逆的匿名设备哈希，辅助 Worker 区分不同安装实例。

## UI Improvements

- 字幕设置和首次 AI 准备向导新增“内置托管服务 / 自定义服务”切换。
- 中、英、日、韩四种界面语言同步更新翻译服务说明。

## 高级配置

在“设置 → 字幕 → AI 服务”中切换到“自定义服务”，即可填写自己的 OpenAI-compatible Chat Completions 地址、模型和 API Key。API Key 会继续使用系统安全存储加密保存在本机。
