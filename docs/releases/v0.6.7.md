## Bug Fixes

AIVPlayer 0.6.7 fixes the macOS startup black screen introduced in 0.6.6 and improves the download fallback shown when a browser cannot reliably identify its CPU architecture.

- 修复 macOS 0.6.6 启动后主窗口全黑的问题：ASR 首次启动状态条加入后，播放器主体的 Grid 布局没有同步扩展，导致主体高度计算为 0；现在两个状态条和播放器主体各自占据正确的布局行。
- 移除 macOS 启动时不必要的 Launch Services 目录扫描，减少启动阶段的额外开销。
- 修复官网无法可靠确认 CPU 架构时推荐下载按钮不明确的问题；现在会自动展开并聚焦到平台 / 架构选择区，不再猜测可能不兼容的安装包。
- 更新发布流水线使用的 FFmpeg 资产配置，保持后续跨平台发布构建使用固定且可校验的资源。

## Performance and Reliability

- macOS 启动流程不再执行不必要的目录扫描。
- 发布后的 macOS、Windows 和 Linux 安装包继续通过版本、格式、架构、资源和 SHA-256 门禁校验。
