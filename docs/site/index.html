ONE APP, THE WHOLE CUT

Less tool switching.
More time with the story.

AIVPlayer keeps the everyday video workflow close: watch, understand, select, and shape without handing your library to a cloud service.

01

Subtitles that stay close

Generate local subtitles with whisper.cpp, translate through an OpenAI-compatible service when you choose, and export the result as a clean sidecar file.

✦
02

Find the frame you remember

Build a local visual library with SigLIP2 and LanceDB. Search by words or an image, then jump straight to the matching moment.

⌕
03

Turn selections into work

Use Clip Inbox, multi-track editing, captions, image tools, and AI short-drama writing in the same local workspace.

01

Install the app

Download the package for your operating system and open your first file.

02

Add a model when needed

Choose a model source inside the app. Nothing large is downloaded silently.

03

Connect AI on your terms

Translation and generation use the endpoint and key you configure, not an AIVPlayer account.
