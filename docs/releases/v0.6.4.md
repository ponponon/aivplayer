## Features

AIVPlayer 0.6.4 improves first-run model preparation, Vision Pack reuse, Linux distribution, and macOS application registration.

- New installations prepare the recommended Whisper model in the background after startup. Downloads use the official R2 mirror first and fall back to ModelScope and Hugging Face when needed.
- Vision Pack archives are content-addressed and reused across application versions when the packaged runtime has not changed. Existing users with older version-based manifests remain supported.
- Linux x64 builds now include a Snap package and Snap Store publishing support in addition to AppImage and deb packages.
- Large release resources can be uploaded to R2 through a resumable multipart-upload script with retry and SHA-256 verification.

## 性能与可靠性

- ASR、Vision 和人物抠像模型下载统一校验远程 manifest、文件大小和 SHA-256，并使用临时文件和原子替换，避免把损坏文件当成可用缓存。
- Vision Pack 本地缓存通过版本映射和 active pointer 选择当前运行时，不会因为目录中存在旧 revision 而误加载历史依赖。
- ASR 模型下载失败会显示进度和错误状态，下一次启动可以继续重试，不阻塞播放器主界面。

## UI Improvements

- macOS 正式应用启动时会清理当前版本及更旧 AIVPlayer Bundle 的 LaunchServices 登记，避免多个挂载 DMG 污染 Finder 的“打开方式”列表。
- 官网和发布清单对默认下载格式使用明确优先级：macOS 优先 DMG、Linux 优先 AppImage、Windows 使用 EXE 安装器；其他格式仍可手动选择。

## Bug Fixes

- 修复 Vision Pack 在本地存在多个历史 revision 时可能继续加载旧版本、跳过当前版本下载的问题。
- 修复默认下载格式依赖清单 JSON 键顺序的问题。
- 修复模型文件“存在但内容不完整或版本错误”时未被及时判定为失效的问题。

## 发布与分发

- Snap 使用 electron-builder 的 core24 / strict 构建策略，x64 版本发布到 Snap Store 的 stable 和 edge 渠道；ARM64 暂不构建 Snap。
- 发布流水线继续对五个平台的安装包、更新元数据、evidence、manifest 和 SHA-256 执行统一校验。
