## Features

- Playback now treats black-section detection as an explicit action. Opening a video only reads an existing analysis cache; when nothing is cached the control bar shows a **Scan black sections** action ("Scanning…" while it runs), and the skip button appears as soon as ranges exist. The editor and the player share the same analysis, so a scan performed in either place is reused by the other.

## Performance and Reliability

- Opening a video no longer starts a full-length FFmpeg decode in the background. Previously the player decoded every frame of the file with `blackdetect` just to know whether the playhead sat in a black section — on a 2-hour 1080p file that meant roughly 5 CPU cores busy for about 9 minutes, and it could not be cancelled. Analysis is now user-triggered, capped to 4 decoder threads, cancelled when you switch media, and cached per file.
- Every external tool process (FFmpeg, FFprobe, whisper.cpp) is now tracked and terminated when AIVPlayer quits. A background analysis or a web transcode can no longer keep running — and keep using CPU — after the window is closed.
- Thumbnail frame extraction is decoded single-threaded. Measured on 1080p material, CPU time per frame drops from 31 ms to 15 ms and wall time from 58 ms to 44 ms, so opening a file no longer spikes every core while the timeline thumbnails are generated.

## UI Improvements

- The playback control bar exposes the analysis state directly: a dedicated scan button when no analysis exists, a progress label while scanning, and the existing skip button when the playhead enters a detected range. Corrections from the editor ("ignore this range") are still honoured by the player.

## Bug Fixes

- Fixed orphaned FFmpeg processes surviving app shutdown on Linux, Windows and macOS.
- Fixed the "skip black section" button appearing for media that had never been analysed, which could only happen after a silent full-file scan had already run.
- Fixed FFmpeg's last error line being dropped for failed analysis, silence detection and metadata probes, so failures now report the real reason instead of a generic command failure.
