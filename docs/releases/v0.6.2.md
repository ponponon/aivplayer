## Bug Fixes

AIVPlayer 0.6.2 fixes macOS automatic update checks for the notarized portable DMG and ZIP packages.

- Added the missing `Contents/Resources/app-update.yml` as a signed extra resource, so `electron-updater` can load the GitHub update source after installation.
- Added a packaged-resource gate that validates the updater configuration before a release can be published.
- Kept the existing user-controlled update flow: checking, downloading, and restarting remain explicit actions.

* * *

## 修复

AIVPlayer 0.6.2 修复 macOS 便携式 DMG / ZIP 安装后的自动更新检查失败问题。

- 将 `Contents/Resources/app-update.yml` 作为签名资源打入 macOS 应用，确保安装后 `electron-updater` 能读取 GitHub 更新源。
- 新增安装包资源门禁，在正式发布前校验更新配置完整存在。
- 保持现有的用户控制更新流程：检查、下载和重启仍由用户明确操作。
