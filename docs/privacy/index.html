AIVPlayer 隐私政策

生效日期：2026 年 8 月 11 日　|　最后更新：2026 年 8 月 11 日

AIVPlayer 的设计原则是“本地优先”：媒体文件、字幕、项目配置和索引默认保留在你的设备上。只有在你主动启用翻译、总结、内容生成、模型下载、更新检查或局域网 Web 播放等功能时，相关请求才会离开设备。

1. 适用范围与发布者

本政策适用于 AIVPlayer 桌面应用及其官方网站。AIVPlayer 由 ponponon 维护。本政策描述当前版本的主要数据处理方式；你使用的第三方 AI 服务、模型下载源、GitHub Releases 以及局域网中的其他设备，还应分别遵守其自己的隐私政策。

2. 我们处理哪些数据

2.1 本地媒体、字幕和项目数据

你导入的视频、图片、Live Photo、音频、字幕、播放记录、项目文件、视觉检索索引、标签和应用设置主要在本机处理和保存。AIVPlayer 当前没有统一的云端账号系统，也没有用于收集这些内容的 AIVPlayer 后台。

2.2 你配置的 AI 服务

当你主动执行字幕翻译、AI 总结、短剧创作或其他生成任务时，应用会把完成该任务所需的文本、提示词、模型参数以及你主动选择的媒体或结果发送到你配置的 OpenAI 兼容服务或其他服务端点。服务地址由你提供，AIVPlayer 不会把这些内容转发到 AIVPlayer 自己的服务器。

你配置的服务地址、模型名称和 API Key 保存在本地。应用在系统支持时使用 Electron safeStorage 调用操作系统安全存储保护密钥；请同时遵守你的操作系统账户安全设置和第三方服务商的保留政策。

2.3 本地 AI 模型与模型下载

语音识别、视觉检索、图像处理等能力可以使用本地模型。首次使用或更新模型时，应用可能从你选择的 ModelScope、Hugging Face 或其他模型源下载模型文件。下载完成后，模型通常保存在本地并由本地运行时使用；模型源可能接收网络请求中的 IP 地址、请求时间、文件路径和客户端网络信息，具体以其政策为准。

2.4 局域网 Web 播放

当你主动开启局域网 Web 播放时，AIVPlayer 会在你的设备上启动本地 Web 服务，并使用访问令牌保护会话。你授权的局域网设备可以读取或播放你选择共享的媒体。该功能不会把媒体上传到 AIVPlayer 云端，但局域网内的设备和网络管理员可能看到连接信息；请只在可信网络中使用。

2.5 更新检查

在支持自动更新的平台上，应用可能连接 GitHub Releases 检查新版本并下载更新。该连接会产生一般网络元数据，例如 IP 地址、时间、操作系统和应用版本；这些数据由 GitHub 按其政策处理。你也可以从 GitHub 或 Gitee 手动下载发布包。

2.6 运行日志与错误信息

应用可能在本地生成运行日志和错误信息，用于诊断问题。除非你主动把日志提交给维护者或第三方服务，否则这些日志不会自动上传到 AIVPlayer。提交日志前请检查并删除 API Key、访问令牌、个人文件路径和其他敏感信息。

3. 我们不会做什么

  • 当前版本没有接入 AIVPlayer 统一后台、广告 SDK 或行为分析 SDK。
  • 我们不会出售或出租你的媒体、字幕、项目文件、API Key 或本地索引。
  • 我们不会在你未主动配置和触发相关功能时，把本地媒体或字幕上传到 AIVPlayer。

4. 保存、删除与权限

本地数据的保存期限由你控制。你可以在应用中删除项目、字幕、索引、模型缓存或设置，也可以使用操作系统的文件管理功能删除对应目录。第三方 AI 服务、模型源、GitHub 和局域网设备可能按照各自政策保留请求记录或缓存，相关删除请求需要直接向对应服务商提出。

AIVPlayer 只会在执行你选择的功能时请求必要的本地文件访问、网络访问或局域网服务能力。你可以通过系统权限设置、应用设置和关闭相关功能来限制这些访问。

5. 安全提示

请不要把 API Key、局域网访问令牌或包含敏感内容的媒体文件提交到公开 Issue。使用第三方 AI 服务前，请确认服务商的地区、数据保留、训练使用和安全条款符合你的要求。任何网络传输都可能受到第三方服务、网络环境和设备安全状况影响。

6. 儿童隐私

AIVPlayer 不是专门面向儿童设计的服务。我们不主动收集儿童个人信息；如果你认为应用处理了不应处理的信息，请通过下方联系方式联系我们。

7. 政策变更

当应用的数据处理方式发生重要变化时，我们会更新本页面的“最后更新”日期，并在适当的产品文档或发布说明中提示变化。继续使用更新后的应用，即表示你可以查看并理解更新后的政策。

8. 联系我们

如果你对隐私政策或数据处理有疑问，可以通过 GitHub Issues 联系维护者。提交时请不要包含 API Key、访问令牌或未脱敏的个人文件。

AIVPlayer Privacy Policy

Effective date: August 11, 2026　|　Last updated: August 11, 2026

AIVPlayer is local-first. Your media, subtitles, projects, and indexes stay on your device by default. Data leaves the device only when you intentionally use translation, summarization, content generation, model downloads, update checks, or LAN web playback.

1. Scope and publisher

This policy applies to the AIVPlayer desktop application and its public website. AIVPlayer is maintained by ponponon. Third-party AI providers, model hosts, GitHub Releases, and devices on your local network have their own privacy policies.

2. Data processing

  • Local content: Imported media, subtitles, projects, playback history, visual indexes, labels, and settings are processed and stored locally. The current version has no AIVPlayer account system or backend that collects this content.
  • Configured AI services: When you start translation, summarization, generation, or another AI task, the required text, prompts, model parameters, and any media you select are sent to the endpoint you configure. AIVPlayer does not route them through an AIVPlayer server.
  • API keys: Service endpoints, model names, and API keys are stored locally. Where supported by the operating system, Electron safeStorage is used to protect secrets. You are responsible for securing your device and reviewing your provider’s retention policy.
  • Model downloads: Local models may be downloaded from ModelScope, Hugging Face, or another source you select. The source may receive ordinary network metadata such as your IP address, request time, and client information.
  • LAN playback: If you enable LAN web playback, a local web server shares only the media you authorize with devices on your trusted network, protected by an access token. Media is not uploaded to an AIVPlayer cloud service.
  • Updates: Supported packaged platforms may check GitHub Releases for updates. GitHub may process ordinary network metadata such as IP address, time, platform, and app version.
  • Logs: Diagnostic logs are generated locally. They are not automatically uploaded to AIVPlayer unless you choose to share them. Remove keys, tokens, paths, and other sensitive information before sharing logs.

3. No sale or advertising

The current version does not use an AIVPlayer backend, advertising SDK, or behavioral analytics SDK. We do not sell or rent your media, subtitles, projects, API keys, or indexes.

4. Retention, deletion, and security

You control local retention and can delete projects, subtitles, indexes, model caches, and settings from the app or your operating system. Third-party providers may retain requests under their own policies. Do not submit API keys, LAN tokens, or unredacted personal files to public issues.

5. Children, changes, and contact

AIVPlayer is not specifically directed to children, and we do not intentionally collect children’s personal information. We will update this page’s date when material data practices change. For questions, contact us through GitHub Issues; do not include secrets or unredacted personal files.
