## Features

AIVPlayer 0.6.5 makes the Linux Snap smaller and fully Wayland-ready, and ships ARM64 Snap builds.

- Linux Snap packages are now built with the GNOME extension on core24: GTK runtime and GL/EGL drivers come from the shared `gnome-46-2404` / `mesa-2404` content snaps instead of being bundled, cutting the download from ~300 MB to ~240 MB (x64) and ~222 MB (arm64).
- Snap builds run in an isolated LXD environment on both x64 and ARM64 runners, keeping the build host clean.
- ARM64 Snap packages are now published automatically to the Snap Store `stable` and `edge` channels; Snap clients pick the right architecture automatically.
- Flatpak bundles are attached to every GitHub Release automatically.

## 性能与可靠性

- 发布流水线遇到超过 Cloudflare R2 REST 单文件限制的安装包时，自动回退为 GitHub Release 直链并保留大小与 SHA-256 校验值，不再阻断整个发布。
- Vision Pack 上传 R2 后的回读校验改为直读 R2 源站，避免 CDN 缓存导致的误判。

## 发布与分发

- Snap Store Listing 已完善：图标、`Photo and Video` 分类、MIT 许可证、官网、源码与 Issue 链接。
- Snap 构建改用 gnome extension 后，沙箱内可访问 mesa GL 驱动，Wayland 会话下渲染不再依赖宿主机库。
