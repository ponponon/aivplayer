## Features

AIVPlayer 0.6.1 brings a more complete Clip Inbox workflow, clearer local update controls, and a release page that is easier to download from in mainland China.

### Clip Inbox collection workflow

- Save and restore collection filters locally, including text search, multi-tag matching, include / exclude tags, and all / active / favorite / archived views.
- Save named filter views and import or export them as versioned JSON files.
- Preview filter-view import conflicts before writing, then choose whether to overwrite, keep, or skip each conflicting view.
- Sort collections by last update, name, clip count, or duration, with stable ordering and persisted preferences.
- Undo and redo tag and favorite / archive operations, with a read-only operation history timeline that survives app restarts.

### Updates and product information

- Added a ChatGPT-style update dialog with skip-this-version, remind-me-later, download, and restart-and-update actions.
- Added a macOS application-menu entry for checking updates manually.
- Added an ISO 8601 release date to the native About panel, cross-platform About dialog, and Settings page.

### Downloads and website

- The website download area now recommends the available package for the detected platform and architecture, while keeping manual selection and historical releases available.
- Added domestic R2 download mirrors for the latest two releases and kept GitHub Releases as the historical fallback.
- Improved Linux platform branding and added Debian packages to the domestic download mirror.

## Bug Fixes

- Fixed delayed playback state updates from an old media instance or React updater overwriting the current play / pause state.
- Fixed release metadata and package synchronization details that could leave the website or Flatpak metadata showing the previous version.
- Fixed macOS release signing and notarization workflow stability for the portable DMG and ZIP packages.

## 功能更新

AIVPlayer 0.6.1 完善了 Clip Inbox 选段集合工作流，提供更清晰的本地更新控制，并让中国大陆用户更容易下载桌面安装包。

### Clip Inbox 选段集合工作流

- 支持在本地保存和恢复集合筛选条件，包括文本搜索、多标签匹配、包含 / 排除标签，以及全部 / 活跃 / 收藏 / 已归档视图。
- 支持保存命名筛选视图，也可以将筛选视图导出或导入为版本化 JSON 文件。
- 导入筛选视图前先预览冲突，用户可以逐条选择覆盖本地、保留本地或跳过导入。
- 支持按最近更新、名称、选段数量或总时长排序，并持久化排序偏好和稳定排序结果。
- 支持撤销和重做标签、收藏 / 归档操作，并提供跨应用重启保留的只读操作历史时间线。

### 更新与产品信息

- 新增 ChatGPT 风格更新弹窗，支持跳过此版本、稍后提醒、下载和重启更新。
- macOS 应用菜单新增手动检查更新入口。
- macOS 原生关于面板、跨平台关于弹窗和设置页新增 ISO 8601 格式的发布日期。

### 下载与官网

- 官网下载区会根据检测到的平台和架构推荐可用安装包，同时保留手动选择和历史版本入口。
- 最新两个版本新增国内 R2 下载镜像，更早版本继续从 GitHub Releases 下载。
- 优化 Linux 平台标识，并将 Debian 安装包同步到国内下载镜像。

## 修复

- 修复旧媒体实例或延迟 React updater 回写播放状态，覆盖当前播放 / 暂停状态的问题。
- 修复发布元数据和安装包同步细节，避免官网或 Flatpak 元数据继续显示上一版本。
- 修复 macOS 便携式 DMG / ZIP 的签名和公证发布流程稳定性问题。
